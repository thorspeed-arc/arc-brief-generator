# ARC Governance Artifacts

This folder contains governance documentation for the ARC, Adversarial Reasoning Council.

These artifacts define the operating model, decision authority, workflow structure, and verification standards that support the ARC Brief Generator.

## Included Documents

- ARC Charter v1.5  
  Defines council structure, roles, authority model, and execution framework.

- ARC SOP v1.5  
  Defines operational workflow, phase structure, risk classification, and execution procedures.
